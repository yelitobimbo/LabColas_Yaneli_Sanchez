# LabColas_Yaneli

Práctica de colas en Java (Estructuras de Datos).

Autor: Yaneli Sanchez Cardenas

## Contenido
- ColaArreglo: cola con arreglo circular
- Nodo y ColaEnlazada: cola con nodos enlazados (genéricos)
- PruebaQueue y PruebaVacia: uso de la interfaz Queue
- Banco: simulación de fila de banco
- PruebaRefuerzo: ejercicios imprimirCola() y vaciar()

## Cómo ejecutar
javac -d out src\colas\*.java
java -cp out colas.Main
